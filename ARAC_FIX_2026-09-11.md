# ARAC / Race 13-16 language + armor fix - 2026-09-11

This revision fixes the custom-race language masks and re-syncs armor proficiency
passives for already existing characters.

## Client/server DBC changes

The same corrected DBC files must be used by the client patch and by the
AzerothCore server DataDir/dbc directory.

### SkillLineAbility.dbc

- Skill 98 / Spell 668 (Common): RaceMask `48205` -> `40013`
  - Common: Human, Dwarf, Night Elf, Gnome, Draenei, Worgen, High Elf, Dark Iron
- Skill 109 / Spell 669 (Orcish): RaceMask `29618` -> `25522`
  - Orcish: Orc, Undead, Tauren, Troll, Goblin, Blood Elf, Mag'har, Ogre
- Skill 111 / Spell 672 (Dwarven): RaceMask `32772` (already correct)
- Skill 137 / Spell 813 (Thalassian): RaceMask `4608` (already correct)

### SkillRaceClassInfo.dbc

The native-language entries (`Flags = 0x80`) are normalized to the same masks:

- Common: `48205` -> `40013`
- Orcish: `62399` -> `25522`
- Dwarven: `32772` (already correct)
- Thalassian: `512` -> `4608`

The armor rows were verified and all include races 1-16. Most use RaceMask `65535`; the Death Knight Plate row uses the wider mask `262143`, which also contains all race bits 1-16. This covers Cloth (415), Leather (414), Mail (413), Plate (293), and Shield (433).

Corrected DBC files are present in both locations:

- `data/patch-A.MPQ/DBFilesClient/`
- `data/server_dbc_fix/`

## SQL changes

`2026_09_11_00_arac_custom_race_skills.sql` provides explicit default language
SkillLines/spells for races 13-16 and preserves the standard class-based armor
SkillLines.

`2026_09_11_01_arac_all_classes.sql` fills missing `playercreateinfo` rows for
all ten WotLK classes for every race 1-16 that already has a server-side race
start entry. Existing custom start rows are never overwritten.

## Existing character repair

`src/mod_coreless_compat.cpp` now repairs existing custom-race characters on
login:

- calls `LearnDefaultSkills()` and `LearnCustomSpells()`;
- normalizes both language spells and 300/300 language SkillLines;
- removes wrong cross-faction default languages from the custom races;
- re-runs `learnSkillRewardedSpells()` for owned armor SkillLines so passive
  Cloth/Leather/Mail/Plate/Shield proficiencies are shown again where the class
  and level permit them.

## Intended language mapping

- Race 13 High Elf: Common + Thalassian
- Race 14 Mag'har Orc: Orcish
- Race 15 Ogre: Orcish
- Race 16 Dark Iron Dwarf: Common + Dwarven
