# Baercraft 6.1 Ogre TEST4

Focus: Ogre + stable custom-race locale/reputation cleanup. Dark Iron is not included.

## Important fixes
- Medviten v1.0.3 Ogre assets remain the client asset base.
- Race 13 High Elf faction template corrected from the erroneous 1 to 2237.
- Reputation masks rebuilt by parent race instead of broad Alliance/Horde OR masks:
  - Worgen -> Human
  - Goblin -> Orc
  - High Elf -> Night Elf (Alliance)
  - Mag'har -> Orc
  - Ogre -> Orc
- High Elf, Mag'har and Stonemaul home reputations apply only to their own race.
- Custom home-faction names localized for enUS/deDE/frFR/esES/ruRU/zhCN/zhTW.
- Character creation descriptions expanded in Blizzard-like style.
- Starting location is explicitly displayed in the race description.
- Racial bonuses are shown for Worgen, Goblin, High Elf, Mag'har and Ogre.
- Ogre uses the real v1.0.3 male/female player assets and displays 62110/62111.

## Notes
Blood elves and high elves are closely related Thalassian elves, but this mod treats High Elves as Alliance-loyal quel'dorei with Alliance reputation, not as Horde blood elves.
